# 5o5o噪音计

一款实时音频频谱分析工具（Android）。上半屏显示实时频谱曲线与峰值标签，下半屏为滚动瀑布图，留存频率历史。支持截图、实时 WAV 录音、暂停定格与多组采集/显示参数设置。

## 功能特性

- 实时频谱曲线 + 峰值标签（dB / Hz），峰值数可设 0~5 个
- 瀑布图留存频率历史，占比可调
- 顶部按钮：截图、录音、暂停、设置；频谱区点击弹菜单（重置峰值保持）
- 多级抽取 FFT 管线：对数频率聚合、指数平滑（0.00~0.95 滑动调节）、消除直流分量
- 音频设置：音频来源、采样率、变换间隔、FFT 分箱数、采样次数、窗函数
- 显示设置：配色主题、频率轴、瀑布图占比、峰值保持轨迹、保持屏幕常亮
- 所有数据仅保存在本机，不上传任何服务器

常见问题
为什么数字不动？ 先检查是否暂停了显示，以及是否允许麦克风权限。关闭其他正在占用麦克风的应用后，再重新进入。
为什么视频黑屏或闪光没反应？ 检查相机权限和其他应用是否占用相机；部分前置镜头没有补光灯。先保存记录，再重新进入视频页面尝试。
为什么停止后还要等？ 应用需要完成音视频收尾并保存文件，等待时间与片段长度及手机状态有关。看到保存完成后再进行下一次操作。
保存失败怎么办？ 检查剩余存储空间和权限，保留错误信息。不要立即卸载或清除数据，以免删除仍暂存在应用中的文件。
